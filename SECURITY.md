# Security Policy

## Supported Versions

Security fixes are provided for the latest major version. Version 3 requires Node.js 22 or newer.

## Reporting

Please report vulnerabilities through GitHub security advisories when available, or contact `info@corbat.tech`.

Include:

- Affected version.
- Environment and Node.js version.
- Reproduction steps.
- Expected and actual behavior.
- Security impact.

## Disclosure

Maintainers will acknowledge reports as soon as practical, triage severity, and coordinate a fix before public disclosure when the issue is valid.
