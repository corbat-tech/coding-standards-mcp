# Corbat MCP Benchmark Report v2.0

## Executive Summary

This report presents the results of a comprehensive benchmark comparing code quality generated by LLMs **with** and **without** Corbat MCP active, using an improved methodology designed to better isolate the impact of MCP guidance.

### Key Findings

| Category | Without MCP | With MCP | Improvement |
|----------|:-----------:|:--------:|:-----------:|
| Basic (3 scenarios) | - | - | -% |
| Intermediate (3 scenarios) | - | - | -% |
| Advanced (4 scenarios) | - | - | -% |
| **Overall (10 scenarios)** | **-** | **-** | **-** |

---

## Methodology v2.0

### Improvements from v1.0

| Aspect | v1.0 | v2.0 |
|--------|------|------|
| **Prompts** | Detailed with hints | Minimalist, no hints |
| **Scenarios** | 6 basic/medium | 10 (basic, intermediate, advanced) |
| **Patterns** | Standard CRUD | Saga, Circuit Breaker, Event Sourcing |
| **Isolation** | Partial | Complete MCP removal |
| **Metrics** | Manual scoring | Automated + qualitative |

### Test Categories

1. **Basic** (Scenarios 01-03): Tasks where LLMs are already capable
   - UserService, REST API, React Form

2. **Intermediate** (Scenarios 04-06): Tasks where MCP provides guidance
   - Kafka Consumer, FastAPI Async, Go Repository

3. **Advanced** (Scenarios 07-10): Tasks where MCP significantly improves output
   - Saga Pattern, Circuit Breaker, Event Sourcing, State Machine

### Prompt Design Principles

- **Minimalist**: Only functional requirements, no architectural hints
- **Identical**: Exact same prompt used for both conditions
- **Complete isolation**: Fresh sessions, no prior context

## Appendix

### Scoring Methodology

| Category | Weight | 1-3 (Poor) | 4-6 (OK) | 7-10 (Good) |
|----------|--------|------------|----------|-------------|
| Architecture | 25% | Monolithic | Basic separation | Hexagonal/Clean |
| Testing | 20% | Minimal tests | Basic coverage | AAA, edge cases |
| Error Handling | 20% | Generic try-catch | Some errors | Full hierarchy |
| DI | 20% | Hardcoded | Constructor | Interfaces |
| SOLID | 15% | Violations | Partial | Complete |

### Formula

```
Total = (Arch × 0.25) + (Test × 0.20) + (Error × 0.20) + (DI × 0.20) + (SOLID × 0.15)
```
